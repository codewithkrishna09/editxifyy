# Editxify 🌐

A modern 3D interactive website built using Three.js and modern web technologies.  
Designed to deliver immersive visual experiences with smooth animations and responsive design.

---

## 🚀 Overview

Editxify is a 3D-powered modern website that combines frontend creativity with backend logic.  
It focuses on interactive UI, smooth transitions, and immersive visual effects.

---

## ✨ Features

- 3D interactive elements using Three.js
- Smooth animations & transitions
- Responsive modern UI
- Optimized performance
- Backend integration using Python

---

- HTML5
